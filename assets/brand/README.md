# Brand sources

Exported from the Figma file "Pizzalator Assets" (vector asset kit): logos, wordmarks, the Pizza Percent symbol,
app icons and favicons. Colours: baked orange `#E8863A`, espresso `#15110F`, warm cream `#F3EDE4`.

Not bundled with the app. Where they are used:

- Launcher icon: `android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` (adaptive, mark from
  `pizzalator-app-icon-dark.svg` as `drawable/ic_launcher_foreground.xml`) and the `mipmap-*dpi` PNGs cut from
  `pizzalator-app-icon-dark@4x.png`.
- In-app mark (empty states): `lib/widgets/mark.dart`, drawn from `pizzalator-symbol-orange.svg`.
