# mockups/

Screen mockups and design system for Pizzalator.

- `*.dc.html` — one file per screen, the source of the live canvas at https://claude.ai/artifact/XuJ1zbQAjXfsVx3gASPYiJ
- `canvas.json` — frame positions, titles and notes for that canvas
- `DESIGN.md` — design guidelines (principles, layout, colour, type, motion, Flutter mapping)
- `design-system/project/` — tokens, brand book and component specs; published at https://claude.ai/artifact/XcWQBSgPqbYJuPU3DMNgYt

Spec lives in `../spec/PRD.md`.
