# mockups/

Screen mockups and design system for Pizzalator.

- `*.dc.html` — one file per screen
- `canvas.json` — frame positions, titles and notes for the screens laid out as one canvas
- `DESIGN.md` — design guidelines (principles, layout, colour, type, motion, Flutter mapping)
- `design-system/project/` — tokens, brand book and component specs

Spec lives in `../spec/PRD.md`.
